# Restaurante e Pizzaria Cardozo's

Landing page institucional e de pedidos da Cardozo's, feita em HTML, CSS e JavaScript vanilla.

## Estrutura

- `index.html`: conteúdo e estrutura semântica da página.
- `assets/css/styles.css`: estilos responsivos e identidade visual.
- `assets/js/main.js`: atualização automática do ano no rodapé.
- `assets/images/`: imagens locais em WebP.

## Desenvolvimento local

Abra `index.html` no navegador. Para servir por HTTP, execute `python -m http.server 8000` na pasta do projeto e acesse `http://localhost:8000`.

## Deploy na Vercel

Importe o repositório como projeto estático, selecione o preset **Other**, deixe o comando de build vazio e use a raiz do projeto como diretório de saída.

Antes de publicar, confirme os preços ilustrativos exibidos no cardápio.
